# Secret Safe - Quick User Guide

## 🔒 What is Secret Safe?

Secret Safe is a hidden, PIN-protected section of your notes app where you can store private notes separately from your regular notes. These notes are stored in a completely separate database for maximum security.

## 🚀 How to Access Secret Safe

### Method: Double-Click the Search Icon

1. **Locate the Search Icon**: Find the search icon (🔍) in the top-right corner of your home page
2. **Double-Click**: Quickly click the search icon **twice** (within 0.3 seconds)
3. **Enter PIN**:
   - **First Time**: You'll be asked to create a 4+ character PIN
   - **Returning**: Enter your existing PIN to unlock

### Note:
- **Single Click** = Opens normal search
- **Double Click** = Opens Secret Safe

## 🎨 Visual Differences

### Regular Notes
- Light purple/blue gradient
- White/light background
- Standard file icons

### Secret Safe
- Deep purple/indigo gradient
- Dark, mysterious theme
- Lock icons 🔒
- "Secret Notes" in header

## ✨ Features in Secret Safe

Everything you can do with regular notes:

- ✅ Create, edit, and delete notes
- ✅ Add tags to organize
- ✅ Pin important notes
- ✅ Create folders
- ✅ Search within secret notes
- ✅ Rich text editing
- ✅ File attachments (PDF, images)

## 🔐 Security

- **Separate Database**: Secret notes are stored in a completely different MongoDB database
- **PIN Protection**: Access requires your personal PIN
- **User-Specific**: Only you can see your secret notes
- **No Cross-Contamination**: Regular notes and secret notes never mix

## 📝 Creating Your First Secret Note

1. Double-click search icon and enter PIN
2. Click "+ New Note" or the create button
3. Title your note
4. Write your content
5. Add tags if needed
6. Click "Save"

## 🔄 Returning to Regular Notes

Click the **← Back Arrow** in the top-left corner of Secret Safe to return to your regular notes.

## ⚠️ Important Notes

- **Remember Your PIN**: There's currently no recovery mechanism
- **PIN Minimum**: At least 4 characters required
- **Auto-Save**: Notes auto-save like regular notes
- **Separate Search**: Searching in Secret Safe only searches secret notes

## 🎯 Tips

- Use Secret Safe for:
  - Personal journal entries
  - Passwords and sensitive info
  - Private ideas or projects
  - Confidential work notes
  - Anything you want extra privacy for

- PIN best practices:
  - Use a memorable but secure PIN
  - Don't share your PIN
  - Choose something longer than 4 characters for better security

## 🐛 Troubleshooting

**Can't access Secret Safe?**
- Make sure you're double-clicking fast enough (within 0.3 seconds)
- Try hovering over the search icon to see the tooltip

**Forgot PIN?**
- Currently, you'll need to contact support or reset your account

**Secret notes not saving?**
- Check your internet connection
- Make sure backend server is running
- Check browser console for errors
